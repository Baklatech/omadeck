# omadeck

Презентации прямо в терминале, в духе Omarchy. Один файл на Python без зависимостей;
цвета берутся из текущей темы Omarchy (`~/.local/state/omarchy/current/theme/colors.toml`).

```
./install.sh            # команда omadeck в ~/.local/bin, ярлык и пункт в меню Omarchy
omadeck                 # стартовое меню: список презентаций, новая, демо, иконки
omadeck demo            # что умеет
omadeck new talk.deck   # собрать презентацию в мастере
omadeck edit talk.deck  # править готовую в том же мастере
omadeck talk.deck       # показать
omadeck icons           # набор иконок по областям
```

Без установки то же самое работает как `./omadeck.py …`.

## Установка

`./install.sh` ставит программу в `~/.local` (с `--system` — в `/usr/local`), добавляет
ярлык для лаунчера и, на Omarchy, пункт **Omadeck** в меню (блок между маркерами
`// >>> omadeck >>>` в `~/.config/omarchy/extensions/omarchy-menu.jsonc`; перед правкой
делается резервная копия). `./install.sh --uninstall` убирает всё обратно.

Пункт меню открывает стартовое меню omadeck. Оно показывает `*.deck` из текущей папки
и из `~/Presentations` (другая папка — переменной `OMADECK_DIR`); новые презентации,
созданные из него, сохраняются туда же.

## Клавиши показа

| Клавиша | Действие |
|---|---|
| `→` `пробел` `Enter` `l`, клик, колесо вниз | дальше (первое нажатие доигрывает анимацию) |
| `←` `Backspace` `h`, правый клик, колесо вверх | назад |
| `g` / `G` | первый / последний слайд |
| число, `Enter` | перейти к слайду |
| `o` `Tab` | оглавление: стрелки и `Enter` |
| `b` | погасить экран (любая клавиша возвращает) |
| `t` | часы и таймер доклада в подвале |
| `r` | перечитать файл и повторить слайд |
| `?` | справка |
| `q` | выход |

`Esc` только закрывает справку и оглавление — случайно закрыть показ им нельзя.
Если файл презентации изменился на диске, он перечитывается сам: удобно держать
рядом редактор. Пока идёт показ, мышь занята им; выделить текст можно с `Shift`.

## Мастер

`omadeck new` задаёт вопросы по слайду и показывает список слайдов. В любом ответе `<`
возвращает на шаг назад (в многострочном вводе — на предыдущую строку). В списке:

| Команда | Действие |
|---|---|
| `+` / `+N` | добавить слайд в конец / вставить перед слайдом N |
| `N` | править слайд: прежние ответы подставляются в строку ввода, стёртая строка текста удаляется |
| `-N` | удалить |
| `N>K` | переместить |
| `p` / `pN` | показать без записи (с начала / со слайда N) |
| `Enter` | записать |

`omadeck edit FILE` открывает в мастере готовый файл. Слайды, которые вы не меняли,
записываются обратно как были — с комментариями и вашим форматированием; заново
собирается только текст изменённых слайдов (комментарии `//` внутри них пропадают).
Пустая строка в тексте слайда вводится и показывается как строка из одной точки.

## Формат файла

Обычный текст. Слайды разделяются строкой `---`, первая строка `@вид параметры`
задаёт вид слайда, строка `# …` — заголовок. Без `@` получится текстовый слайд
(или таблица, если в теле есть строки с `|`). Строки с `//` в начале — комментарии.

```
title: Название в подвале
effect: decrypt            // необязательно: один эффект на все заголовки

---
@title
# Большой заголовок
Подзаголовок
автор · дата

---
@section
# Раздел
пояснение

---
# Просто текст
Абзац с **жирным**, *курсивом* и `кодом`.
- пункт
  - вложенный
1. нумерованный
> цитата

---
@split icon=rocket side=left
# Текст и иконка
- текст на одной половине, анимированная иконка на другой

---
@chart type=line unit=%
# График
| Месяц | 2025 | 2026 |
| Янв | 12 | 18 |
| Фев | 15 | 24 |

---
@table
# Таблица
| Сервис | Реплик |
|---|---|
| api | 6 |
```

**Графики** — `type=` `bar` (по умолчанию), `hbar`, `line`, `pie`, `donut`.
Данные — строки `метка: значение` (несколько рядов: `метка: 1; 2; 3` и `series=A,B,C`)
или таблица, где первый столбец — метки, остальные — ряды. Ещё параметры: `unit=`, `min=`, `max=`.

**Таблицы** — каждая строка файла `| a | b |` — один ряд, первая — шапка. `@table grid`
рисует линейки между рядами; строка `|---|:---:|---:|` задаёт выравнивание столбцов.

**Эффекты заголовка** — `decrypt`, `beams`, `rain`, `slide`, `wipe`, `print`, `scatter`,
`expand`, `matrix`, `vhs`. По умолчанию выбирается случайный; закрепить можно на слайде
(`@title effect=matrix`), в шапке файла (`effect: beams`) или при запуске (`-e vhs`).

**Иконки** для `@split icon=…` — 70 штук, `omadeck icons` показывает их по областям:

| Область | Иконки |
|---|---|
| Техника | omarchy terminal server database cloud cpu git wifi lock gear sync search radar cube atom chart |
| Работа и учёба | briefcase calendar clock hourglass target check bulb rocket book cap users star warning bolt |
| Здоровье и спорт | heart pulse medkit apple dumbbell ball bike trophy |
| Природа | tree flower sun moon mountain drop fire globe umbrella paw |
| Дом, быт и деньги | home key food coffee gift cart coin card |
| Поездки и досуг | plane car pin compass music palette camera gamepad |
| Общение и общество | mail phone chat scales building flag |

Слайд `@icons group=nature` вставляет галерею одной области в презентацию
(`tech`, `work`, `health`, `nature`, `home`, `leisure`, `people`).

Крупный шрифт заголовков знает латиницу, кириллицу, цифры и основную пунктуацию; если
заголовок не помещается или в нём есть другие символы, он выводится обычным текстом.
Текст, который не поместился на слайд, не пропадает молча: внизу пишется, сколько
строк не влезло.

`examples/demo.deck` — исходник демонстрации, удобно взять за образец
(`omadeck sample my.deck` запишет его копию).
