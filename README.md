# omadeck

Презентации в терминале, в цветах темы Omarchy.

```bash
git clone https://github.com/Baklatech/omadeck && cd omadeck && ./install.sh
omadeck demo            # что умеет
omadeck new talk.deck   # собрать свою
omadeck talk.deck       # показать
```

[Формат файла и клавиши](docs/guide.md).
