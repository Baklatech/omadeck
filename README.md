# omadeck

Презентации прямо в терминале, в духе Omarchy. Один файл на Python без зависимостей;
цвета берутся из текущей темы Omarchy (`~/.local/state/omarchy/current/theme/colors.toml`).

```
./omadeck.py demo            # что умеет
./omadeck.py new talk.deck   # собрать презентацию в мастере
./omadeck.py edit talk.deck  # править готовую в том же мастере
./omadeck.py talk.deck       # показать
./omadeck.py icons           # набор иконок
./install.sh                 # поставить как команду omadeck в ~/.local/bin
```

## Мастер

`omadeck new` задаёт вопросы по слайду и показывает список слайдов. В любом ответе `<`
возвращает на шаг назад (в многострочном вводе — на предыдущую строку). В списке:
`+` — добавить, `N` — править слайд (прежние ответы подставляются в строку ввода,
стёртая строка текста удаляется), `-N` — удалить, `N>K` — переместить, `Enter` — записать.

`omadeck edit FILE` открывает в мастере готовый файл. Слайды, которые вы не меняли,
записываются обратно как были — с комментариями и вашим форматированием; заново
собирается только текст изменённых слайдов (комментарии `//` внутри них пропадают).
Пустая строка в тексте слайда вводится и показывается как строка из одной точки.

## Клавиши

| Клавиша | Действие |
|---|---|
| `→` `пробел` `Enter` `l` | дальше (первое нажатие доигрывает анимацию) |
| `←` `Backspace` `h` | назад |
| `g` / `G` | первый / последний слайд |
| число, `Enter` | перейти к слайду |
| `r` | перечитать файл и повторить слайд |
| `?` | справка |
| `q` `Esc` | выход |

## Формат файла

Обычный текст. Слайды разделяются строкой `---`, первая строка `@вид параметры`
задаёт вид слайда, строка `# …` — заголовок. Без `@` получится текстовый слайд
(или таблица, если в теле есть строки с `|`). Строки с `//` в начале — комментарии.

```
title: Название в подвале
effect: decrypt            // необязательно: один эффект на все заголовки

---
@title
# Большой заголовок
Подзаголовок
автор · дата

---
@section
# Раздел
пояснение

---
# Просто текст
Абзац с **жирным**, *курсивом* и `кодом`.
- пункт
  - вложенный
1. нумерованный
> цитата

---
@split icon=rocket side=left
# Текст и иконка
- текст на одной половине, анимированная иконка на другой

---
@chart type=line unit=%
# График
| Месяц | 2025 | 2026 |
| Янв | 12 | 18 |
| Фев | 15 | 24 |

---
@table
# Таблица
| Сервис | Реплик |
|---|---|
| api | 6 |
```

**Графики** — `type=` `bar` (по умолчанию), `hbar`, `line`, `pie`, `donut`.
Данные — строки `метка: значение` (несколько рядов: `метка: 1; 2; 3` и `series=A,B,C`)
или таблица, где первый столбец — метки, остальные — ряды. Ещё параметры: `unit=`, `min=`, `max=`.

**Таблицы** — каждая строка файла `| a | b |` — один ряд, первая — шапка. `@table grid`
рисует линейки между рядами; строка `|---|:---:|---:|` задаёт выравнивание столбцов.

**Эффекты заголовка** — `decrypt`, `beams`, `rain`, `slide`, `wipe`, `print`, `scatter`,
`expand`, `matrix`, `vhs`. По умолчанию выбирается случайный; закрепить можно на слайде
(`@title effect=matrix`), в шапке файла (`effect: beams`) или при запуске (`-e vhs`).

**Иконки** — `omadeck icons` показывает все 28: omarchy, rocket, gear, globe, heart, clock,
bulb, server, database, cloud, lock, terminal, star, check, warning, target, radar, atom,
cube, git, bolt, coffee, chart, cpu, wifi, search, sync, users.

Крупный шрифт заголовков знает латиницу, кириллицу, цифры и основную пунктуацию; если
заголовок не помещается или в нём есть другие символы, он выводится обычным текстом.

`examples/demo.deck` — исходник демонстрации, удобно взять за образец
(`omadeck sample my.deck` запишет его копию).
